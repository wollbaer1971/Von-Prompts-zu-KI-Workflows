\chapter{Apps, Skills, Plugins und MCP}
Apps verbinden ChatGPT mit externen Informationen oder Aktionen. Skills beschreiben wiederverwendbare Arbeitsweisen. Plugins können mehrere Fähigkeiten bündeln. MCP ist ein offenes Protokoll, über das ein KI-System Werkzeuge und Ressourcen eines Servers entdecken und aufrufen kann.

\begin{merke}Skill = Wie wird gearbeitet? App = Mit welchem Dienst? MCP = Wie werden Werkzeuge standardisiert angeboten?\end{merke}
